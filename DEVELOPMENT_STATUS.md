## Как проверить (шаг 2.1)
1. Дождаться зелёной сборки в GitHub Actions, скачать `.jar` из Artifacts.
2. Положить `.jar` в папку `mods` тестового Forge 1.20.1 сервера (с читами/OP).
   **Важно:** если тестируешь на уже существующем мире, где Mining World
   раньше сгенерировался как плоский (Этап 1) — удали папку
   `world/dimensions/moggminingworld/mining_world` перед стартом, иначе
   старые плоские чанки останутся на месте и новая генерация будет видна
   только на новых, ранее не посещённых координатах.
3. Запустить сервер, проверить лог на строку про "Mining World dimension is
   registered and loaded" (как и раньше).
4. Зайти оператором, выполнить:
   ```
   /execute in moggminingworld:mining_world run tp @s 0 60 0
   ```
   (координата Y = 60, а не -60 — теперь это середина полной колонны высот,
   в отличие от плоской заглушки Этапа 1).
5. Ожидаемый результат: игрок оказывается либо в камне (тогда нужно
   `/execute in moggminingworld:mining_world run tp @s 0 100 0` или ещё выше,
   чтобы попасть в воздух над пещерами), либо сразу видит пещерный рельеф —
   неровные своды, гроты, обычный камень/глубинный сланец. Копая вверх —
   упираешься в bedrock. Копая вниз — тоже bedrock. Неба и облаков нет.
6. **На что специально посмотреть и сообщить в следующем сообщении:**
   - есть ли большие полости, залитые водой (это нормально ожидать на этом
     шаге — воду ещё не трогали, это будет отдельный шаг 2.6);
   - нет ли крашей чанк-генератора в логе.
7. Вернуться: `/execute in minecraft:overworld run tp @s 0 100 0`.

## Известные проблемы / ограничения
- Биом временный (`minecraft:dripstone_caves` как placeholder) — значит пока
  идут ванильные декорации/мобы этого биома, ванильные звуки/цвет тумана.
  Заменится своим биомом в шаге 2.2.
- Вода **не трогалась** на этом шаге — большие пещеры могут быть залиты,
  как и раньше. Это специально отдельный шаг 2.6, не пытался чинить заранее.
- Нет способа попасть в измерение через игровой интерфейс (только команда) —
  это ожидаемо, портал будет на Этапе 6.
- gradlew/gradle-wrapper.jar по-прежнему не добавлены (см. ограничение Этапа 0);
  сборка всё ещё идёт через `gradle/actions/setup-gradle` в GitHub Actions.
