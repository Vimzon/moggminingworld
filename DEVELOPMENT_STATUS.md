- **Измерение Mining World зарегистрировано через датапак:**

    нет неба (`has_skylight: false`), есть потолок (`has_ceiling: true`),
    эффекты как у Края (`effects: minecraft:the_end`, значит нет солнца/луны/облаков),

    пока **временный плоский мир-заглушка**: bedrock (1 блок) → stone (5 блоков) →
    bedrock (1 блок), биом `the_void`. Это НЕ финальная генерация — она будет
    заменена на нормальные пещеры на Этапе 2.
- `MoggMiningWorld.java` — добавлен публичный `ResourceKey<Level> MINING_WORLD_KEY`,
  ссылающийся на `moggminingworld:mining_world`.
- `ModEvents.java` — новый класс, слушает `ServerStartingEvent` и пишет в лог,
  найдено ли измерение при старте сервера (для лёгкой проверки без захода в игру).

## Как проверить
1. Дождаться зелёной сборки в GitHub Actions, скачать `.jar` из Artifacts.
2. Положить `.jar` в папку `mods` тестового Forge 1.20.1 сервера (с читами/OP).
3. Запустить сервер, открыть его лог. Должна появиться строка:
   ```
   [Mogg Mining World] Mining World dimension is registered and loaded: moggminingworld:mining_world
   ```
   Если вместо этого warning "was NOT found" — что-то не так с JSON-файлами
   измерения, писать об этом в следующем сообщении Claude.
4. Зайти на сервер игроком с правами оператора (`/op <ник>` в консоли сервера,
   если ещё не оператор).
5. Выполнить команду (это ванильная Minecraft-команда, не мод-специфичная):
   ```
   /execute in moggminingworld:mining_world run tp @s 0 -60 0
   ```
6. Ожидаемый результат: игрок телепортируется, видит вокруг тёмное пространство
   без неба и облаков, под ногами каменная площадка, по бокам и снизу через
   несколько блоков — bedrock. Это нормально для Этапа 1 — генерация ещё плоская.
7. Вернуться обратно можно так:
   ```
   /execute in minecraft:overworld run tp @s 0 100 0
   ```
   (или на свои прежние координаты).
