# Mogg Mining World — Development Status

Текущий этап: **Этап 0 — Подготовка проекта**
Версия: 0.1.0-stage0
Minecraft: 1.20.1
Forge: 47.2.0
Java: 17

## Что уже реализовано
- Базовая структура Gradle-проекта Forge-мода.
- `settings.gradle` — подключает репозиторий Forge Maven.
- `build.gradle` — конфигурация ForgeGradle, mappings=official 1.20.1, Java toolchain 17.
- `gradle.properties` — метаданные мода (mod_id, версия, версии MC/Forge).
- `src/main/resources/META-INF/mods.toml` — метаданные мода для Forge (шаблонизируется через processResources).
- `src/main/resources/pack.mcmeta` — обязательный файл ресурспака.
- `src/main/java/com/mogg/miningworld/MoggMiningWorld.java` — главный класс мода, аннотация `@Mod`, только логирование запуска.
- `.gitignore` — исключены build/, run/, IDE-файлы.
- `.github/workflows/build.yml` — CI-сборка через GitHub Actions (см. ниже, ВАЖНО).

## ВАЖНОЕ ОГРАНИЧЕНИЕ ЭТОГО ЭТАПА
Файлы `gradlew`, `gradlew.bat` и `gradle/wrapper/gradle-wrapper.jar` **пока не включены в проект**.

Причина: генерация корректного `gradle-wrapper.jar` требует либо установленного Gradle
локально, либо доступа к серверам Gradle/Forge для его скачивания — в среде, где эти файлы
готовились, такого доступа не было.

Из-за этого сборка на Этапе 0 проверяется **не локально**, а через GitHub Actions
(`.github/workflows/build.yml`), который использует `gradle/actions/setup-gradle` и
вызывает `gradle build` напрямую, без обёртки (wrapper).

**Что нужно сделать пользователю (владельцу репозитория) на этом этапе:**
1. Запушить проект в GitHub.
2. Открыть вкладку Actions и посмотреть, прошла ли сборка (зелёная галочка / красный крестик).
3. Если сборка красная — скопировать текст ошибки из лога и передать его в следующий диалог с Claude для исправления.
4. Полноценный `gradlew`/`gradle-wrapper.jar` для локальной сборки должен быть добавлен на
   одном из следующих этапов — либо взят из официального Forge MDK (files.minecraftforge.net),
   либо сгенерирован командой `gradle wrapper --gradle-version 8.1.1` при наличии локально
   установленного Gradle.

## Как проверить (после того как Actions прошёл зелёным)
- В артефактах (Artifacts) запуска Actions должен появиться `moggminingworld-jar` с файлом
  `moggminingworld-0.1.0-stage0.jar`.
- Наличие самого jar-файла на этом этапе — это и есть критерий успеха. Запускать сервер/клиент
  пока не обязательно, т.к. мод ничего не делает кроме строчки в логе.
