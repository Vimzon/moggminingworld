# Mogg Mining World

Forge-мод для Minecraft 1.20.1 (Forge 47.2.0, Java 17). Добавляет отдельное
измерение **Mining World** (`moggminingworld:mining_world`) — полностью
подземный мир для добычи руд: без поверхности, неба, воды и лавы.

## Возможности
- **Закрытое пещерное измерение** 0..320: сплошной камень, пещеры как в
  верхнем мире, бедрок-потолок и рваный бедрок-пол, скрытый толщей породы.
- **Ванильные руды**: уголь, медь, железо, золото, редстоун, лазурит,
  алмаз, изумруд — диапазоны как в Overworld, плюс жирные «кэши-карманы»
  по глубине.
- **Руды других модов** (Create, Mekanism, Thermal и т.д.) авто-подхватываются:
  сканирование реестра блоков, распределение по глубине как в Overworld.
- **Структуры**: заброшенные шахты, комнаты монстров, сталактиты/сталагмиты.
- **Мобы**: ванильные пещерные мобы (зомби, скелеты, пауки, криперы,
  эндермены, летучие мыши); убитые в Mining World мобы с шансом роняют руды.
- **Атмосфера**: туман глубины (чем глубже — тем плотнее и темнее), время
  всегда «полночь», нет неба/облаков.
- **Телепорт-блок** `mining_portal` — вход/выход (только порталом).
- **Настройки** (`config/moggminingworld-common.toml`): высоты/плотности
  руд, скорость предгенерации, «ограничение копания вверх», дроп руд с мобов.
- **Интеграции**: WorldEdit работает из коробки; DimWorldBorder +
  `/moggminingworld pregen start` — предгенерация чанков.

## Установка
1. Minecraft 1.20.1 + Forge 47.2.0.
2. Положить `moggminingworld-*.jar` в папку `mods`.
3. (Опционально) второй мод с рудами, DimWorldBorder, WorldEdit.

## Игровой процесс
- Вход: поставить `mining_portal` в Overworld (`/give @s
  moggminingworld:mining_portal`) и нажать ПКМ.
- Выход: ПКМ по порталу внутри Mining World.
- Админ-команды: `/moggminingworld pregen start|stop|status [radius]`.
- Задать границу мира майнинга: `/dimworldborder moggminingworld:mining_world set <размер>`.

## Сборка
```
./gradlew build
```
Готовый jar — `build/libs/moggminingworld-*.jar`.
